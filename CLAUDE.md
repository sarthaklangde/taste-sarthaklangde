# taste.sarthaklangde.com

Sarthak's restaurant picks. Fully static Vite + React + Tailwind + shadcn site, deployed on Vercel from `main`.

## Data
- `data/places/<id>.json`: one published place each. Shape in `src/lib/types.ts`.
- `data/dishes.json`: shared dish explainers, keyed by dish id. One explainer per dish, reused by every place.
- `inbox/<id>.json`: drafts waiting for Sarthak's review. Same shape plus `newDishes`.
- Cuisines, cities and verdict labels live in `src/lib/catalog.ts`.
- `src/generated/data.json` bundles places and dishes. Regenerated by `pnpm data` (runs before dev, build and publish). Committed so Vercel functions can import it.

## Adding places
1. Sarthak dictates raw notes, often several at once.
2. Spawn one `enricher` subagent (Haiku) per place, in parallel. Each writes `inbox/<id>.json`.
3. Run `pnpm check-inbox`, fix anything invalid, then show Sarthak each draft as a short card.
4. Apply his revisions to the inbox file.
5. When he approves: `pnpm publish-place <id>`, then commit. Push only when he says deploy.

Never publish without his approval. Never add opinions he didn't give.

## URL and link previews
Filters are query params so any view is shareable: `?city=lisbon&cuisine=indian&q=tikka+masala`.
- `src/lib/view.ts` turns params into title, description and results. The app, `api/page.ts` and `api/og.ts` all use it. Keep its imports relative.
- `vercel.json` routes `/` to `api/page.ts` only when `city`, `cuisine` or `q` is set. It serves `index.html` with the tags between `<!-- og:start -->` and `<!-- og:end -->` swapped for that view. Do not use Vercel middleware here: it crashed the whole site once (Oct 2026).
- `api/og.ts` draws the 1200x630 preview image. Pinned to `@vercel/og@0.9.0` because 1.0.3 ships without a wasm file it needs.

## Git
- Work on `main`. No branches or PRs (Sarthak's call, overrides the workspace rule).
- Batch changes: commit locally as you go, but do not push. Pushing to `main` deploys to production.
- When a batch is ready, list the unpushed commits (`git log origin/main..main --oneline`) and ask Sarthak to deploy. Push only after he says yes.

## Design
Sarthak likes the current look; keep it. Playful sticker style: cream background, Bricolage Grotesque headings, thick black borders with offset shadows, bright pastel fills, emoji, small tilts and bouncy hovers. Layout borrows from Lu.ma: city picker, one row of cuisine pills under it, compact place rows that expand, city grid at the bottom.
